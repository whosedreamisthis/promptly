# Feature History

- **Clerk Authentication:** Installed `@clerk/nextjs` and added `proxy.ts` with Clerk middleware (no protected routes yet). Added Sign in and Register buttons to the nav bar (`components/layout/NavBar.tsx`) that open modal sign-in/sign-up and also link to the `app/(auth)/sign-in` and `app/(auth)/register` pages. Supports Google and email/password, with links to switch between sign-in and sign-up. `.env.example` documents `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` and `CLERK_SECRET_KEY`.

- **Sidebar:** Added a full-height sidebar (`components/sidebar/`: `Sidebar`, `AppShell`, `SidebarSection`, `SidebarItem`, `ItemMenu`, `SettingsModal`) with a new `Logo`. It has a header with logo, "Promptly" title and an X close button, a search box, New chat, collapsible Notebooks and Recents sections with a scroll divider, and a footer with avatar, name, "Free Tier" and a settings modal. Rows have a ⋮ menu: chats get share, pin, rename, add to notebook and delete; notebooks get pin, rename and delete. The sidebar closes fully when an option is clicked and reopens from a hamburger icon with the title beside it; below 768px it is a drawer with a backdrop. The top navbar only shows when signed out. Also applied the pastel palette (gradient background, glass navbar, lavender scrollbars). Data is mock, in `lib/mock-chats.ts`. Added `lucide-react`.
